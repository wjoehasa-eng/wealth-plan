# 입주 자금관리 (PWA)

2028년 9월 입주 목표까지 **얼마가 모자란지 1초에 보는** 설치형 웹앱입니다.
나중에 주식 포트폴리오 관리로 확장할 수 있게 설계했습니다.

- 이 저장소의 파일에는 **개인 정보가 한 글자도 없습니다.** 이름·계좌번호·주소·실제 금액은
  코드가 아니라 사용자 본인의 **비공개 구글 시트**에만 저장됩니다.
- 앱은 기본적으로 **빈 상태**로 시작합니다. 직접 입력하거나, 구글 시트에서 불러오거나,
  JSON 백업 파일로 채웁니다.
- 화면의 `예시 데이터` 버튼은 설명용 숫자(10억·3억 등 둥근 값)일 뿐 실제 자료가 아닙니다.

### 개인대출 — 입주용 / 주택 무관 (v4.6)

- **대출현황 → 개인대출**의 추가·수정 폼 위에 **공무원연금공단 · 교직원공제회 · 직접 입력** 칩이 있어
  한 번 눌러 기관명이 들어갑니다.
- 체크박스는 **🏠 입주 자금에 쓰기 (확보 재원 포함)** / 해제 시 **별도 (주택 무관)** 로 표시가 바뀝니다.
- 목록 위에 **입주용 합계(계산 포함)** 와 **주택 무관 별도 합계(계산 제외)** 를 숫자로 나란히 보여 줍니다.
  입주용 합계는 `목록에서 체크한 금액 + 시뮬레이터 개인 추가 대출`입니다.
- 목록 배지는 초록 **입주용**, 회색 **별도** 입니다. 둘 다 이 카드의 주황색 합계(총 대출)에는 들어갑니다.
- 요약 탭 **자금 구조**와 **자금 브릿지**에서는 두 항목을 나누지 않고 **개인 추가 대출** 한 줄(막대)로 보여 줍니다.

### 금액을 원·만 원 단위까지 (v4.5)

- 화면의 모든 금액은 뭉뚱그리지 않고 **1원 단위까지** 보여줍니다. (`123,456,789원` → `1억 2,345만 6,789원`, `987,654,321원` → `9억 8,765만 4,321원`)
- 목록·카드의 큰 금액은 **만 원 단위**까지, 작은 금액은 원까지 표시합니다.
- **자금 브릿지·잔액 추이 차트의 눈금과 막대 위 숫자만** 좁은 자리 때문에 `15.6억`·`9,500만`처럼 줄여 씁니다(글자 겹침 방지).

### 시뮬레이터 정밀 조절 (v4.5)

- **주식 자산**·**입주 시 신규·승계 주담대** 슬라이더의 한 칸이 **1,000만 원 → 100만 원**으로 10배 촘촘해졌습니다.
- 슬라이더 오른쪽 **금액(✎)**을 누르면 그 자리에서 **원 단위 금액을 직접 입력**할 수 있습니다(Enter 저장, Esc 취소).
- 직접 입력은 **잠금을 푼 상태**에서만 열립니다. 잠겨 있으면 먼저 🔒 잠금을 풀라는 안내가 나옵니다.

### 납입일정 `현금` / `대출` / `잔금` (v4.5)

- 일정마다 자금 성격 뱃지가 붙습니다 — **💵 현금**(내 돈), **🏦 대출**(중도금대출·주담대), **🏠 잔금**.
- `+ 추가`·`✎ 수정` 폼의 **자금 성격**에서 바꿀 수 있습니다. 구분을 입력하면 합리적인 기본값이 자동으로 잡힙니다.
  - `계약금`·`옵션`·`중도금 6차` 이상 → **현금**, `잔금`·`잔금 옵션` → **잔금**, `중도금 1~5차`(메모에 `자납`이 없으면) → **대출**.
- 시트 `납입일정`은 **기존 5열 그대로**입니다. 기본값과 다른 성격을 고르면 메모 끝에 `#현금`/`#대출`/`#잔금` 표식이 붙어 시트를 오가도 유지됩니다(화면에는 표식을 빼고 보여 줍니다).
- 완료 항목의 "내 돈 / 대출" 구분도 이 성격을 따릅니다(대출 성격은 "이미 낸 내 돈"에서 빠짐).

### 💵 앞으로 필요한 현금 (시기별) (v4.6)

요약 탭의 이 카드는 **앞으로 언제 얼마가 필요한지**를 두 단계로만 보여 줍니다. 슬라이더를 움직이면 즉시 다시 계산됩니다.

- **맨 위 요약** — `앞으로 낼 현금 합계` − `모을 돈(월급 누적 + 주식 자산 + 개인 추가 대출)`
  = **최종 부족(여유)**. 이 값은 맨 위 KPI의 `최종 부족분`과 **1원까지 같습니다**(같은 계산값 사용).
- **① 입주 전** (예: 중도금 6차 납입일) — **`낼 돈 (현금 자납)` 금액만** 보여 줍니다.
  (v4.7: 월급은 매달 대출 상환에 쓰이므로 `그때까지 모이는 돈` · 여유/부족 배지를 걷어냈습니다. 일정이 여러 개면 합계도 같이.)
- **② 입주 시점** (입주 목표일 · 잔금·취득세) — `월급 반영 후 필요한 현금`
  (= 잔금·취득세 등 − 전세금 − 입주까지 월급 누적), 그리고 `①+② 필요 − 주식 자산`으로 최종 부족을 한 번 더 확인.
- 긴 계산식은 **계산 자세히 보기** 안에 접어 두었습니다(주담대 초과분·잔금·취득세·후불이자·월급 누적·주식 안분).

### 편집(관리자) 모드 — 실수 삭제 방지

- 기본은 **읽기 전용**입니다. 목록(납입일정·상환내역·개인대출·주식) 오른쪽의 **✕ 삭제**·**✎ 수정** 버튼과
  납입일정의 상태 버튼이 **보이지 않습니다**.
- 오른쪽 위 **편집** 버튼(🔒)을 누르면 주황색 **편집 중** 배지로 바뀌고, 그때만 삭제·수정 버튼이 나타납니다.
  행 배경도 살짝 주황으로 변해 편집 중임을 알 수 있습니다.
- 편집 모드는 **저장되지 않습니다** — 화면을 새로 고치거나 앱을 다시 열면 자동으로 **OFF**로 돌아갑니다.

### 시뮬레이터 잠금 — 스크롤하다 값이 바뀌지 않게

- 시뮬레이터 슬라이더 4개는 **기본이 잠금**입니다. 화면을 스크롤하다 스치거나 가볍게 눌러도 값이 바뀌지 않습니다
  (슬라이더가 흐리게 보이고 라벨 옆에 🔒 표시).
- **꾹 누르기**: 슬라이더를 **0.35초** 누르고 있으면 지원 기기에서 짧게 진동(`navigator.vibrate(25)`)하고
  그 슬라이더만 풀립니다. 손을 뗀 뒤 드래그해 조절하고, 손을 떼고 잠시(약 1.2초) 지나면 다시 잠깁니다.
- **헤더 토글**: 카드 오른쪽 위 **🔒 잠금 / 🔓 조절** 버튼으로 네 개를 한 번에 켜고 끕니다(PC·연속 조절용).
- 잠금 상태는 저장되지 않으며, 앱을 다시 열면 항상 잠긴 상태로 시작합니다.

### 중도금 대출 구조 기록 규칙 (2026-11-20)

중도금 대출이 **이자후불제가 아니라 매달 이자를 직접 내는 구조**라면 시트를 이렇게 유지합니다.

- `설정` 의 **`중도금후불이자`는 0** 으로 둡니다. 입주 때 한꺼번에 낼 돈이 아니므로 총 목표에 넣지 않습니다
  (넣어 두면 이미 낸 이자와 겹쳐 이중 계산이 됩니다).
- 매달 낸 이자는 `대출상환` 탭에 그 달의 행으로 남깁니다(상환원금·납입이자·합계·거래후잔액).
  `거래후잔액`은 그때의 실제 잔액, `금리(%)`는 그 기간에 실제로 적용된 금리(역산 가중평균)입니다.
- 1차·2차 중도금처럼 **같은 계좌에 차수가 누적 실행**되면, 실행 직후 첫 상환 행의 `거래후잔액`에
  **합산된 잔액**을 적고 메모에 어느 차수인지 남깁니다. 그래야
  `대출상환` 누적 상환원금 + `설정` 의 `현재대출잔액` = 실행된 중도금 총액이 맞아떨어집니다.
- 앱은 저장할 때 각 탭을 기기 상태로 통째로 바꿉니다. 시트를 손으로 고친 뒤에는 앱 ⚙ 설정에서
  **‘시트에서 불러오기’를 한 번** 눌러 기기에도 같은 값이 들어오게 해야 다음 저장에 지워지지 않습니다.

### 계산식 (v4)

```
총 목표         = 목표 금액(분양가·옵션) + 취득세·등기비 + 중도금 후불이자
이미 낸 내 돈   = 대출상환 탭의 상환 원금 합계
                 + 납입일정에서 '완료'인 자납 항목(계약금·옵션·자납 등)
                 ※ 중도금·대출로 실행된 완료 항목은 제외 — 남은 대출 잔액이 목표 안에 있음
앞으로 남은 필요 = max(0, 총 목표 − 이미 낸 내 돈)
확보 재원       = 전세금 회수 + 신규·승계 주담대 + 개인 추가 대출(목록 입주용 + 시뮬레이터)
                 + 주식 자산(평가+수익+배당) + (월 투입 × 남은 개월)
최종 부족분     = 앞으로 남은 필요 − 확보 재원   (음수면 여유)
달성률          = (이미 낸 내 돈 + 확보 재원) ÷ 총 목표
필요 월 저축액   = (남은 필요 − 전세금 − 주담대 − 개인 추가 대출 − 주식 자산) ÷ 남은 개월
필요 주식 자산   = 남은 필요 − 전세금 − 주담대 − 개인 추가 대출 − 월급 누적
```

**내 대출현황**은 위 계산과 따로 보는 요약입니다. **두 시점으로 나눠** 보여 주고, 두 합계를 더하지 않습니다.

```
지금(오늘)      = 대출상환 탭의 최근 잔액(중도금·기존 주택대출) + 등록된 개인대출 전체
입주 시(대환 후) = 신규·승계 주담대 + 개인 추가 대출(입주용: 목록+시뮬) + 주택 무관 별도 개인대출(유지)
```

· 중도금 잔액은 입주 때 주담대·전세·현금으로 **상환(대환) 완료**되어 사라집니다.
  그래서 `중도금 잔액 + 신규 주담대`를 한 합계로 더하면 같은 빚을 두 번 세는 것처럼 보입니다(v4.7에서 분리).
· 개인 추가 대출은 입주 때 빌리는 돈이라 **확보 재원에 더해져 부족분을 줄입니다**(대신 개인대출이 늘어남).
  시뮬레이터 슬라이더와 대출현황에서 **🏠 입주 자금에 쓰기**를 체크한 개인대출은 같은 항목으로 합쳐 계산합니다.
· 체크하지 않은 **별도(주택 무관)** 개인대출은 표시 전용입니다 — 입주 자금 부족분 계산에 섞지 않습니다.

### ⚖️ 월 저축 ↔ 주식 자산 시소 (v4.7.1 — 독립 시뮬)

- **1번 시뮬레이터와 완전히 분리된 가상 시뮬레이션입니다.** 이 카드에서 값을 움직여도 1번 시뮬레이터의
  월 저축·주식 자산, 화면 위 KPI, 이 기기 저장(localStorage), 구글 시트는 **바뀌지 않습니다**(저장 안 됨).
- 가로 = **가상 월 저축**, 세로 = **가상 주식 자산**. 두 값을 합쳐 부족분이 0원이 되는 경계가 **점선 하나**로 그려집니다.
  (`가상 월 저축 × 남은 개월 + 가상 주식 자산 = 남은 필요 − 전세금 − 주담대 − 개인 추가 대출`)
- 선 **위는 여유(초록)**, 선 **아래는 부족(빨강)**. 회색 동그라미 = 1번 시뮬레이터 기준값, 파란 점 = 지금 시소 위치.
- **차트를 탭하거나 끌면** 그 위치로 점이 바로 이동합니다(마우스·손가락 모두, 카드 안에서만 동작, 페이지는 스크롤되지 않음).
- 카드 안의 **큼직한 슬라이더 2개**(가상 월 저축 · 가상 주식 자산)는 1번 시뮬레이터의 🔒 잠금과 상관없이 바로 밀 수 있습니다.
- 카드 아래 **컬러 막대**가 `월 저축 누적` + `주식 자산` 합계를 `부족 0원 목표`와 나란히 보여 줍니다(비어 있는 빗금 = 아직 모자란 금액).
- **월 저축 고정 → 필요 주식** · **주식 고정 → 필요 월 저축** 은 가상 값 하나만 균형값으로 옮기고, **↺ 기준값으로** 는 1번 시뮬레이터의 현재 값으로 되돌립니다.
  (월 저축은 슬라이더 한 칸인 10만 원 단위로 **올림**해 부족이 남지 않게 맞춥니다.)
- 1번 시뮬레이터의 월 저축·주식 자산을 바꾸면 시소도 그 새 기준값에서 다시 시작합니다(주담대·전세금이 바뀌면 균형선만 따라 움직입니다).

### 잔액 추이 — 실선 + 예상 점선 (v4.7)

- **실선** = 지금까지 실제 기록. 상환으로 내려가고 새 중도금 대출이 실행되면 계단처럼 올라간 모습이 그대로 보입니다.
- **점선** = 예상. 마지막 기록 **다음 달**부터 매달 `월 투입`(요약 시뮬레이터 슬라이더)만큼 원금이 줄고,
  `납입일정`에 남아 있는 **자금 성격 '대출'** 일정(예: 중도금 3·4·5차)이 도래하는 달에 그 금액만큼 계단처럼 올라갑니다.
  **입주 목표일**에는 그 계좌가 대환으로 0원이 되는 점까지 이어집니다.
- 카드 오른쪽 위 **`실선+점선` / `실선만`** 버튼으로 점선을 끄고 켤 수 있습니다(끄면 Y축도 실선 범위에 맞춰 다시 잡힘).
  선택은 이 기기에 기억됩니다. 요약 탭에서 `월 투입`을 바꾸면 점선 기울기도 바로 바뀝니다.
- 점선은 **월 투입 전액을 원금 상환으로 보는 가정**입니다(매달 내는 이자 몫은 빼지 않음). 실제 원금 감소가 더 느리면 점선보다 잔액이 높게 남을 수 있습니다.

**이중 계산 금지**: 목표 금액에는 총 분양가(옵션·부대비용 포함)를 넣고, 이미 낸 계약금·자납 중도금과
지금까지 갚은 대출 원금은 앱이 **자동으로 빼서** 계산합니다. 기존 대출 잔액은 목표 안에 포함된 것으로
보아 **따로 또 빼지 않습니다**(v2 이전의 `기존대출상환반영` 옵션은 이 때문에 제거 — 시트의 Y/N 값은 무시).

신호등: 달성률 **100% 이상 = 여유**, **97~100% = 근접**, 그 아래 = 부족.

월별 투입은 *앞으로의 속도*를 재는 값입니다. 이미 모인 돈은 전세금·주식 평가금으로 잡히므로
이중으로 더하지 않습니다.

## 파일

```
index.html               앱 본체 (HTML/CSS/JS 한 파일)
manifest.webmanifest     설치형 앱 정보
sw.js                    오프라인 캐시(앱 껍데기만)
icon-192.png
icon-512.png
icon-512-maskable.png
apps-script/Code.gs      구글 시트 백엔드(Apps Script)
```

## 배포 (GitHub Pages)

1. 새 저장소를 만들고 이 폴더의 파일을 그대로 올립니다. (Settings → Pages → Branch: main / root)
2. 폰에서 `https://<계정>.github.io/<저장소>/` 를 열고 **홈 화면에 추가**합니다.
3. 파일을 고친 뒤에는 `sw.js`의 `CACHE` 이름(현재 `wealth-plan-v4-7`)의 버전을 올려야
   폰에 새 화면이 반영됩니다. 서비스 워커는 새 버전을 받으면 **즉시 활성화**되고,
   열려 있던 화면은 한 번 자동 새로고침되어 바로 새 코드로 바뀝니다.

## 구글 시트 백엔드 (5분, 한 번만)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (이름은 자유, 예: `내 자금관리 데이터`)
2. 그 시트에서 **확장 프로그램 → Apps Script** 를 열고, 기본 내용을 지운 뒤
   `apps-script/Code.gs` 내용을 붙여 넣고 저장합니다.
3. **배포 → 새 배포 → 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `.../exec` URL을 복사합니다.
4. 앱 오른쪽 위 **⚙ → 구글 시트 연결** 에 URL을 붙여 넣고
   **연결하고 불러오기** 를 누릅니다. (연결은 항상 *불러오기부터* 합니다.)
   `docs.google.com/spreadsheets/…` 주소를 넣으면 그 자리에서 안내가 나옵니다.

시트 탭은 스크립트가 자동으로 만들고, 없으면 아래 구성으로 생깁니다.

```
설정           항목 | 값 | 비고
대출상환       날짜 | 상환원금 | 납입이자 | 합계 | 거래후잔액 | 금리(%) | 메모
납입일정       구분 | 예정일 | 금액 | 상태 | 메모
월별투입       월 | 투입금액 | 구분 | 메모
주식포트폴리오 종목명 | 수량 | 매수단가 | 현재가 | 평가금액 | 수익금 | 비고
개인대출       대출명 | 잔액 | 금리(%) | 비고 | 입주포함(Y/N)   ← v4.4
```

### 동기화 동작 (v2)

- **자동 불러오기**: 앱을 열 때, 다른 앱에서 돌아올 때(포커스·화면 복귀), 20초마다 시트를 확인해
  시트가 더 최신이면 화면을 그대로 갱신합니다. PC에서 고치면 폰에서 몇 초 안에 보입니다.
- **자동 저장**: 대출상환·주식·납입일정·설정을 바꾸면 1초 뒤 자동으로 시트에 저장합니다.
  (연속 입력은 마지막 입력 기준으로 한 번만 보냅니다.)
- **빈 상태 보호**: 목표금액·대출·주식·일정이 모두 비어 있으면(기존 `월별투입` 기록 포함) **절대 시트로 저장하지 않습니다.**
  예시 데이터도 시트로 보내지 않습니다.
- **시트가 비어 있을 때**: 이 기기에 자료가 있으면 시트를 그 자료로 덮어쓰지 않고, 이 기기 자료를 유지한 채
  “이 기기 데이터를 시트로 저장”을 안내합니다.
- **상태 표시**: 오른쪽 위 점 — 초록=최신, 노랑=동기화 중, 회색=미연결, 빨강=오류.
  자동 저장·자동 불러오기 결과는 화면 위쪽 짧은 알림으로도 보입니다.
- **충돌**: 두 기기가 같은 순간에 고치면 나중에 저장된 쪽이 남습니다(기기 시계 기준 ±2초 여유).
- **한 단계 되돌리기**: 시트에서 불러오기·백업 불러오기·예시 데이터 적용·전체 삭제 직전의 상태를
  기기에 하나 보관하고, ⚙ 설정 → 데이터의 **직전 상태 되돌리기**로 되돌립니다.

### 동작 방식과 한계

- **불러오기**는 JSONP(스크립트 태그)로 동작해 CORS 제약이 없습니다.
- **저장**은 `text/plain` POST로 보냅니다. Apps Script가 응답 헤더를 주지 않아 브라우저가
  응답을 가릴 수 있는데, 그때 앱은 시트를 한 번 더 읽어 `savedAt` 값을 대조해
  **실제로 저장됐는지 확인**합니다. 확인되지 않으면 그렇게 표시합니다.
- 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영됩니다.
- **v4 항목(개인대출·취득세·후불이자·개인 추가 대출)은 Code.gs도 v4여야 시트에 저장됩니다.**
  구버전 Code.gs를 그대로 쓰면 앱은 오류 없이 돌지만 그 항목은 **이 기기에만** 남고,
  ⚙ 설정에 그 사실이 표시됩니다. 새 `apps-script/Code.gs`로 다시 배포하면 함께 저장됩니다.
- **v4.4 개인대출 ‘입주포함’ 열**도 같습니다. 4칸짜리 예전 `개인대출` 시트는 새 Code.gs로 한 번 저장할 때
  `입주포함` 열이 생기고 기존 행은 N(별도)이 됩니다. 열이 생기기 전에는 앱이 이 기기의 체크 값을 지킵니다.
- 급하게 쓰지 않을 때는 앱의 **JSON 내보내기**로 백업을 남기세요. 파일에는 입력한 금액이
  들어 있으니 공유하지 마세요.
