# 입주 자금관리 (PWA)

2028년 9월 입주 목표까지 **얼마가 모자란지 1초에 보는** 설치형 웹앱입니다.
나중에 주식 포트폴리오 관리로 확장할 수 있게 설계했습니다.

- 이 저장소의 파일에는 **개인 정보가 한 글자도 없습니다.** 이름·계좌번호·주소·실제 금액은
  코드가 아니라 사용자 본인의 **비공개 구글 시트**에만 저장됩니다.
- 앱은 기본적으로 **빈 상태**로 시작합니다. 직접 입력하거나, 구글 시트에서 불러오거나,
  JSON 백업 파일로 채웁니다.
- 화면의 `예시 데이터` 버튼은 설명용 숫자(10억·3억 등 둥근 값)일 뿐 실제 자료가 아닙니다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 요약·시뮬 | D-Day, **자금 구조**(총 목표 → 이미 낸 내 돈 → 앞으로 남은 필요 → 확보 재원 → 최종 부족분), 필요 월 저축액·필요 주식 수익, 자금 브릿지 차트, 3개 시뮬레이터 슬라이더, 납입 일정(자납/대출 표시) |
| 대출상환 | 누적 원금/이자, 잔액 감소 추이 그래프, 상환 내역 추가(잔액 자동 차감) |
| 현금흐름 | 월별 투입 막대 그래프, 월평균·최근 3개월 평균 투입 속도, 월 필요 투입과 비교 |
| 주식 | 종목별 평가금·손익, 합계가 요약 탭 확보 자산에 자동 합산 |

### 계산식 (v3)

```
이미 낸 내 돈   = 대출상환 탭의 상환 원금 합계
                 + 납입일정에서 '완료'인 자납 항목(계약금·옵션·자납 등)
                 ※ 중도금·대출로 실행된 완료 항목은 제외 — 남은 대출 잔액이 목표 안에 있음
앞으로 남은 필요 = max(0, 총 목표 금액 − 이미 낸 내 돈)
확보 재원       = 전세금 회수 + 신규·승계 주담대 + 주식 평가금 + 주식 수익 + (월 투입 × 남은 개월)
최종 부족분     = 앞으로 남은 필요 − 확보 재원   (음수면 여유)
달성률          = (이미 낸 내 돈 + 확보 재원) ÷ 총 목표 금액
필요 월 저축액   = (남은 필요 − 전세금 − 주담대 − 주식 평가금 − 주식 수익) ÷ 남은 개월
필요 주식 수익   = 남은 필요 − 전세금 − 주담대 − 주식 평가금 − 월급 누적
```

**이중 계산 금지**: 목표 금액에는 총 분양가(옵션·부대비용 포함)를 넣고, 이미 낸 계약금·자납 중도금과
지금까지 갚은 대출 원금은 앱이 **자동으로 빼서** 계산합니다. 기존 대출 잔액은 목표 안에 포함된 것으로
보아 **따로 또 빼지 않습니다**(v2 이전의 `기존대출상환반영` 옵션은 이 때문에 제거 — 시트의 Y/N 값은 무시).

신호등: 달성률 **100% 이상 = 여유**, **97~100% = 근접**, 그 아래 = 부족.

월별 투입은 *앞으로의 속도*를 재는 값입니다. 이미 모인 돈은 전세금·주식 평가금으로 잡히므로
이중으로 더하지 않습니다.

## 파일

```
index.html               앱 본체 (HTML/CSS/JS 한 파일)
manifest.webmanifest     설치형 앱 정보
sw.js                    오프라인 캐시(앱 껍데기만)
icon-192.png
icon-512.png
icon-512-maskable.png
apps-script/Code.gs      구글 시트 백엔드(Apps Script)
```

## 배포 (GitHub Pages)

1. 새 저장소를 만들고 이 폴더의 파일을 그대로 올립니다. (Settings → Pages → Branch: main / root)
2. 폰에서 `https://<계정>.github.io/<저장소>/` 를 열고 **홈 화면에 추가**합니다.
3. 파일을 고친 뒤에는 `sw.js`의 `CACHE` 이름(`wealth-plan-v3` → `v4`)을 올려야
   폰에 새 화면이 반영됩니다. 서비스 워커는 새 버전을 받으면 **즉시 활성화**되고,
   열려 있던 화면은 한 번 자동 새로고침되어 바로 새 코드로 바뀝니다.

## 구글 시트 백엔드 (5분, 한 번만)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (이름은 자유, 예: `내 자금관리 데이터`)
2. 그 시트에서 **확장 프로그램 → Apps Script** 를 열고, 기본 내용을 지운 뒤
   `apps-script/Code.gs` 내용을 붙여 넣고 저장합니다.
3. **배포 → 새 배포 → 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `.../exec` URL을 복사합니다.
4. 앱 오른쪽 위 **⚙ → 구글 시트 연결** 에 URL을 붙여 넣고
   **연결하고 불러오기** 를 누릅니다. (연결은 항상 *불러오기부터* 합니다.)
   `docs.google.com/spreadsheets/…` 주소를 넣으면 그 자리에서 안내가 나옵니다.

시트 탭은 스크립트가 자동으로 만들고, 없으면 아래 구성으로 생깁니다.

```
설정           항목 | 값 | 비고
대출상환       날짜 | 상환원금 | 납입이자 | 합계 | 거래후잔액 | 금리(%) | 메모
납입일정       구분 | 예정일 | 금액 | 상태 | 메모
월별투입       월 | 투입금액 | 구분 | 메모
주식포트폴리오 종목명 | 수량 | 매수단가 | 현재가 | 평가금액 | 수익금 | 비고
```

### 동기화 동작 (v2)

- **자동 불러오기**: 앱을 열 때, 다른 앱에서 돌아올 때(포커스·화면 복귀), 20초마다 시트를 확인해
  시트가 더 최신이면 화면을 그대로 갱신합니다. PC에서 고치면 폰에서 몇 초 안에 보입니다.
- **자동 저장**: 대출상환·현금흐름·주식·납입일정·설정을 바꾸면 1초 뒤 자동으로 시트에 저장합니다.
  (연속 입력은 마지막 입력 기준으로 한 번만 보냅니다.)
- **빈 상태 보호**: 목표금액·대출·현금흐름·주식·일정이 모두 비어 있으면 **절대 시트로 저장하지 않습니다.**
  예시 데이터도 시트로 보내지 않습니다.
- **시트가 비어 있을 때**: 이 기기에 자료가 있으면 시트를 그 자료로 덮어쓰지 않고, 이 기기 자료를 유지한 채
  “이 기기 데이터를 시트로 저장”을 안내합니다.
- **상태 표시**: 오른쪽 위 점 — 초록=최신, 노랑=동기화 중, 회색=미연결, 빨강=오류.
  자동 저장·자동 불러오기 결과는 화면 위쪽 짧은 알림으로도 보입니다.
- **충돌**: 두 기기가 같은 순간에 고치면 나중에 저장된 쪽이 남습니다(기기 시계 기준 ±2초 여유).
- **한 단계 되돌리기**: 시트에서 불러오기·백업 불러오기·예시 데이터 적용·전체 삭제 직전의 상태를
  기기에 하나 보관하고, ⚙ 설정 → 데이터의 **직전 상태 되돌리기**로 되돌립니다.

### 동작 방식과 한계

- **불러오기**는 JSONP(스크립트 태그)로 동작해 CORS 제약이 없습니다.
- **저장**은 `text/plain` POST로 보냅니다. Apps Script가 응답 헤더를 주지 않아 브라우저가
  응답을 가릴 수 있는데, 그때 앱은 시트를 한 번 더 읽어 `savedAt` 값을 대조해
  **실제로 저장됐는지 확인**합니다. 확인되지 않으면 그렇게 표시합니다.
- 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영됩니다.
- 급하게 쓰지 않을 때는 앱의 **JSON 내보내기**로 백업을 남기세요. 파일에는 입력한 금액이
  들어 있으니 공유하지 마세요.

## 데이터 보관 위치

| 위치 | 내용 |
| --- | --- |
| 이 기기 브라우저(localStorage) | 입력·수정한 전체 데이터 |
| 사용자 구글 시트(비공개) | 같은 데이터의 원본 표 |
| 내보낸 JSON 파일 | 백업 |

앱은 위 세 곳 밖으로 데이터를 보내지 않습니다. 외부 분석 도구·광고·CDN을 쓰지 않습니다.
