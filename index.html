설정

기본 값

목표 금액은 총액(분양가+옵션)을 넣으세요. 취득세·등기비와 중도금 후불이자는 여기에 더해져 총 목표가 됩니다(이미 포함했다면 0). 이미 낸 계약금·자납 중도금과 지금까지 갚은 대출 원금은 자동으로 빼고 계산하므로 직접 빼지 않아도 됩니다. 기존 대출 잔액도 목표 금액 안에 포함된 것으로 보아 따로 또 빼지 않습니다.

구글 시트 연결

시트를 처음 준비할 때: 구글 시트 → 확장 프로그램 → Apps Script 에 apps-script/Code.gs를 붙여넣고, 배포 → 새 배포 → 웹 앱(실행: 나 / 액세스: 모든 사용자)으로 배포한 뒤 나오는 .../exec 주소를 위에 넣습니다. 구글 시트 주소(docs.google.com/spreadsheets/…)를 넣으면 연결되지 않습니다.
입력한 값이 모두 0인 빈 상태에서는 시트를 덮어쓰지 않습니다(자료 보호). 시트 자료가 사라졌다면 구글 시트의 파일 → 버전 기록에서 이전 버전으로 되돌릴 수 있습니다.

계산 방식

총 목표 = 목표 금액(분양가·옵션) + 취득세·등기비 + 중도금 후불이자
앞으로 남은 필요 자금 = 총 목표 − 이미 낸 내 돈
· 이미 낸 내 돈 = 대출상환 탭의 상환 원금 합계 + 납입일정에서 완료인 자납·계약금·옵션 (중도금·대출로 실행된 항목은 제외 — 그 돈은 목표 안에 남은 대출로 잡혀 있습니다)
확보 재원 = 전세금 회수 + 신규·승계 주담대 + 개인 추가 대출(대출현황 '입주용' + 시뮬레이터) + 주식 자산(평가+수익+배당) + (월 투입 × 남은 개월)
최종 부족분 = 앞으로 남은 필요 자금 − 확보 재원 (음수면 여유)
필요 월 저축액 = (남은 필요 − 전세금 − 주담대 − 개인 추가 대출 − 주식 자산) ÷ 남은 개월
필요 주식 자산 = 남은 필요 − 전세금 − 주담대 − 개인 추가 대출 − 월급 누적
달성률 = (이미 낸 내 돈 + 확보 재원) ÷ 총 목표. 신호: 100% 이상 = 여유, 97~100% = 근접
내 대출현황은 두 시점으로 나눠 보여 줍니다 — 지금(오늘) = 중도금 잔액 + 등록된 개인대출, 입주 시(대환 후) = 신규·승계 주담대 + 개인 추가 대출(입주용) + 주택 무관 별도 개인대출(유지). 중도금은 입주 때 대환되므로 두 합계를 더하지 않습니다.
개인대출 중 🏠 입주 자금에 쓰기를 체크한 것만 확보 재원에 넣고, 체크하지 않은 별도(주택 무관) 개인대출은 표시만 합니다.
